# Требования

- Сервер Debian или CentOS/Red Hat с установленным Python.
- Компьютер администратора с [Ansible](https://www.ansible.com/).
- Рабочий доступ Ansible по SSH-ключу. Базовая роль по умолчанию отключает SSH-аутентификацию по паролю.
- Выделенный сервер: плейбук управляет Docker, systemd и портами включённых сервисов, поэтому не стоит смешивать его с неуправляемыми службами.

GitLab использует отдельный настраиваемый порт для SSH-клонирования
`gitlab_ssh_host_port` (по умолчанию `2222`); системный SSH может оставаться
на порту `22`.
