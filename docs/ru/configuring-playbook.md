# Настройка плейбука

В корне репозитория выполните следующие действия.

1. Создайте каталог переменных нужного хоста, например:
   `mkdir -p inventory/host_vars/prod`.
2. Скопируйте пример: `cp examples/host-vars.yml inventory/host_vars/prod/vars.yml`.
3. Отредактируйте `vars.yml`: включите нужные роли, задайте имена хостов, пути, версии образов и параметры сервисов.
4. Скопируйте inventory: `cp examples/hosts inventory/hosts`.
5. Отредактируйте `inventory/hosts` и задайте адреса, SSH-порт и имена целей.

Реальные `inventory/` и Vault-секреты не должны попадать в Git. Для паролей,
токенов и ключей используйте `ansible-vault encrypt_string`. Полный список
настроек и их назначение приведён в [описании сервисов](services.md).
