# Обновление

1. Обновите репозиторий, например `git pull`.
2. Сначала примените изменения на тестовой цели:

   ```bash
   make setup-all-and-restart TARGET=test
   ```

3. После проверки примените их на production:

   ```bash
   make setup-all-and-restart TARGET=prod
   ```

Не меняйте версию образа одновременно с восстановлением резервной копии.
Перед обновлением Stateful-сервисов прочитайте их примечания в
[описании сервисов](services.md).
