# Установка

После [настройки плейбука](configuring-playbook.md) примените его к явной
цели inventory:

```bash
make setup-all TARGET=prod
```

Доступные цели — `test` и `prod`. Make запросит пароль Ansible Vault. Для
автоматического запуска можно передать защищённый файл с паролем:

```bash
make setup-all TARGET=prod ANSIBLE_VAULT_ARGS="--vault-password-file /secure/path/vault-password"
```

После установки службы можно перезапустить отдельной командой:

```bash
make start TARGET=prod
```

Некоторым службам, особенно GitLab, требуется несколько минут на первое
запуск и миграции.

## Первый запуск RAID

Перед применением включите `raid_installation_enabled` и внимательно задайте
устройства в переменных RAID-роли. Инициализация RAID может уничтожить данные:
проверьте диски и точки монтирования до запуска.

## Первый запуск GitLab

GitLab в базовой конфигурации рассчитан на LAN и доступен по
`http://gitlab.DOMAIN`. Перед публикацией в Интернет добавьте отдельный
reverse proxy с TLS и аутентификацией. SSH-клонирование по умолчанию использует
порт `2222`, не конфликтуя с SSH сервера.

При первом открытии GitLab предложит установить пароль пользователя `root`.
После входа создайте обычных пользователей и при необходимости отключите
учётную запись root. Встроенный Prometheus GitLab выключен по умолчанию:
репозиторий разворачивает отдельный Prometheus.
