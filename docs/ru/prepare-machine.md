# Подготовка сервера

Перед первым запуском плейбука подготовьте целевой сервер.

1. Скопируйте `prepare_server.sh` на сервер, например: `scp -P 22 prepare_server.sh <user>@<ip>:/home/<user>/`.
2. Подключитесь по SSH: `ssh -p 22 <user>@<ip>`.
3. Сделайте скрипт исполняемым: `chmod +x prepare_server.sh`.
4. Запустите его: `./prepare_server.sh`.
5. После выполнения сервер перезагрузится.

Скрипт меняет порт SSH, параметры root-доступа и настраивает статический IP.
Перед запуском убедитесь, что не потеряете доступ к серверу.
